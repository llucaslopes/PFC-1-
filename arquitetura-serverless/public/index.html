A3 Serverless · Vercel Functions + Vercel KV

Arquitetura serverless do TCC

Esta funcao recebe amostras do ESP32 via Wi-Fi e expoe os endpoints da arquitetura A3. O dashboard visual eh o mesmo do backend Node, apontando para esta URL atraves do selector "Arquitetura" e da querystring ?target=a3&baseUrl=....

Endpoints disponiveis

POST /api/ingest GET /api/health GET /api/data/latest?deviceId=esp32-01 GET /api/metrics GET /api/config POST /api/clock/sync POST /api/experiments/start POST /api/experiments/stop POST /api/experiments/reset GET /api/experiments/current GET /api/experiments/export POST /api/experiments/observations

Como abrir o dashboard

Suba o backend Node localmente e acesse:

http://localhost:3000/?target=a3&baseUrl=https://<seu-projeto>.vercel.app

O dashboard passa a buscar metricas e ultima amostra deste deployment.
